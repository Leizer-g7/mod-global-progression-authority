# Migration Strategy

Production remains on mod-phase-progression V1 during GPA development.

Migration stages:

    1. GPA foundation
    2. GPA Core
    3. Player policy
    4. Profession policy
    5. Playerbots adapter
    6. Individual Progression adapter
    7. V1 functional parity
    8. AH Bot Plus adapter
    9. Extended economy/integration features
    10. Isolated migration test
    11. Production certification

GPA must not replace V1 until functional parity has been demonstrated.

No production database migration should be introduced before the GPA state
model and migration path have been validated against a cloned database.
